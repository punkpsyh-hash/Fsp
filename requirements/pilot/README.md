# Независимый пилот: подготовка, без результатов участников

Пилот ещё не проведён. `observations.csv` содержит только заголовок.
Полный план независимой проверки и предварительного выбора метрик —
`первоначальный сценарий пилота` (архив этапа в закрытой истории). Технические тесты и синтетические задания
не заменяют содержательную проверку практикующими специалистами.

До начала зафиксировать версии, рубрики, правила набора, размер групп,
приемлемые границы метрик и интервал между параллельными формами.
Эксперты оценивают работы вслепую и отдельно от результата теста.
Доступ к правильным ответам между параллельными формами меняет эксперимент:
штатный продукт показывает разбор после завершения, поэтому исследование
нужно проводить в отдельной согласованной среде, не отключая разбор на NAS.

После добровольного согласия хранить наблюдения в отдельном локальном файле
`local-data/pilot/observations.csv`, исключённом Git. Коды P001 и далее;
никаких ФИО, адресов, резюме или секретов. Кодирование не делает реальные
данные автоматически анонимными: ключ соответствия и основания обработки
остаются вне проекта. Не коммитить реальные ответы или отчёты малых групп.

Поля: специализация backend/frontend/qa; заявленный грейд junior/middle;
score 0–100; независимая категория unconfirmed/junior/middle или пустая;
результат параллельной формы 0–100 или пустой; время в минутах или пустое;
точная версия формы. Одна строка на человека/специализацию/заявленный грейд.
Все поля об источниках наблюдений и способе экспертизы описать отдельно.

Анализ шаблона в Docker:

```bash
cd /Volume1/projects/Fsp
FSP_UID="$(id -u)" FSP_GID="$(id -g)" docker compose run --rm -T --no-deps \
  -v "$PWD/requirements/pilot:/pilot:ro" tools python scripts/analyze_pilot.py \
  --input /pilot/observations.csv --output docs/pilot-readiness.json
```

Пустой шаблон даёт `not-conducted`, ноль наблюдений, без придуманных метрик.
Скрипт выводит матрицу экспертная категория × категория теста, долю согласия,
среднюю абсолютную разницу баллов и время, с отдельными знаменателями.
Он не удостоверяет независимость экспертов и не доказывает пригодность теста.
