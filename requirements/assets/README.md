# Материалы дизайна

Оригинал `брендбук.rar` получен; проверены список содержимого и SHA-256.
Четыре исходных SVG-знака сохранены в `brand/`; их имена и контрольные суммы
записаны в `brand/manifest.json`. Знаки не перерисовывались.

Полный архив содержит сторонние фотографии, которые проект не использует.
Для очищенного публичного снимка он исключён; исходник и прежняя история
сохраняются в закрытом `Fsp-private-history` и локально. Отдельные исходные SVG
также не входят в публичный снимок; готовая конкурсная презентация сохранена.
Получение брендбука не означает
передачу проекту прав на его свободное распространение.

Существующая авторская иллюстрация находится в `design/assets/editorial.png`,
промпт — в `design/assets/prompt.txt`. Точные схемы — в `diagrams/` (Mermaid/SVG).
Эти файлы не являются заменой оригинального брендбука.
