## Что изменилось

- Подготовлены краткий README и навигация по актуальной документации.
  Предыдущие редакции доступны в Git history.
- Добавлена самостоятельная инструкция [docs/53](53-self-deployment.md):
  базовый стенд, загрузка Qwen, GPU-запуск и собственный API модели.
- `run.sh` преобразует Windows-пути через `cygpath`, задаёт параметры Git Bash,
  поддерживает `model-fetch`, `model-verify`, `start-llm`, `status-llm`,
  `check-llm`, `stop-llm`, `model-report`. Установка Python/Node на хост не нужна.
- `init_env.py` создаёт случайный ключ локальной модели без перезаписи остальных
  секретов. Пустой существующий ключ отклоняется без изменения `.env`.
- GPU Compose требует ключ; генерация ограничена 120 секундами, обычный
  запрос модели — 100. Первый startup ждёт до 900 секунд; PostgreSQL получает
  start period 120 секунд. Бюджеты CPU/RAM самой модели не повышались.
- Download использует закреплённый commit и SHA-256, временный `.part` и замену
  только после проверки. Проверка offline отклоняет пропуски, изменения,
  лишние файлы, ссылки и небезопасные пути.
- ИИ-коннектор остаётся существующим `OpenAICompatible`; новая абстракция
  или внешние учётные данные не добавлены.
- Transfer metadata, кэши и GitHub workflows исключены из Docker-контекста;
  локальный `TRANSFER-MANIFEST.json` сохранён и исключён из Git.

Исторические генераторы, протоколы, презентации и видео не удалены: на них
ссылаются проверки и документация. «Очистка» означает понятные входные документы,
отделённую историю и исключение частных/временных файлов из передачи.

внешний провайдер и самостоятельный запуск на компьютере жюри не проверены.

Предыдущие байты сохранены отдельно на D вне Git. Имеющаяся исходная копия

Manifest не изменялся; работающий сервис не останавливался.

### Ограничения тестового окружения

На компьютере владельца автоматические Docker address pools исчерпаны другими
проектами. Проверялись существующие подсети; для отдельного проекта
`fspselfdeploy` выбран не пересекающийся локальный диапазон `10.253.238.0/24`.
Host-порты отключены, образы и volumes изолированы. Это отличие лабораторной
пробы от штатного запуска на свободном компьютере описано явно.
В локальном `local-data/selftest.yaml` использовалось дополнение:

```yaml
services:
  db:
    ports: !reset []
  app:
    image: fspselfdeploy-app
    ports: !reset []
  runner:
    image: fspdev-runner
networks:
  default:
    ipam:
      config: [{subnet: 10.253.238.0/24}]
```

Это пример **изолированного теста**, а не универсальный адрес для чужой сети.
Существующий runner image был пересобран из чистого клона; имя image не
является именем Compose-проекта. Владелец не удалял чужие сети и данные.
Штатный пользовательский запуск использует ports из `compose.yaml`.
