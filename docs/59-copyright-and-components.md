# Авторское право и сторонние компоненты

Документ фиксирует происхождение файлов и доступные лицензионные метаданные для очищенного конкурсного выпуска и отдельно обозначенных локальных оригиналов. Это инвентаризация, а не правовое заключение и не подтверждение полной цепочки прав. Машинный перечень версий, заявленных SPDX выражений, исходных URL, хешей и копий текстов лицензий находится в [`third-party-components.json`](third-party-components.json).

## Код проекта

Проектная лицензия не выбрана. Владелец разрешил открытый конкурсный выпуск 11 октября 2026 года; публикация не означает передачу исключительных прав или назначение общей лицензии. Инвентаризация не определяет авторов и правообладателей каждой строки кода и не назначает владельца лицензирующим лицом. Общая лицензия проекта и любые заявления об авторстве требуют отдельного решения владельца.

## Пакеты Python и веб-приложения

Список Python-пакетов получен через `importlib.metadata` внутри существующего образа `fspgost-tools`; сверены версии и установленный состав образа `fspdelivery-app`. Зафиксировано 43 пакета: `python-docx` и `lxml` относятся к tools-образу, остальные присутствуют также в app-образе. У 43 пакетов найдены исходные файлы лицензий/уведомлений в метаданных установленных дистрибутивов; 47 текстов скопированы без изменения в `resources/licenses/third-party/python/`. Для каждой копии сохранён SHA-256. Значения SPDX взяты из метаданных пакета; свободный текст ReportLab и пустое поле `exceptiongroup` не переинтерпретировались как SPDX выражения. Содержимое лицензий и применимость условий к конкретному способу распространения должен оценить юрист.

Для production-зависимостей веб-клиента учтён lock-файл: React 19.3.0, React DOM 19.3.0 и Scheduler 0.28.0. Их MIT LICENSE сохранены в `resources/licenses/third-party/web/`; номера версий, npm registry URL, lock integrity и SHA копий перечислены в JSON. Dev/test пакеты не включены в этот production dependency closure.

## Проверка и ограничения

Отдельный монтаж видео использует Remotion 4.0.534, React 19.2.3 и существующий
шрифт DejaVu. Его lockfile, копии лицензий и происхождение компонентов
хранятся в `video/`; они не относятся к dependency closure веб-приложения
в прежнем реестре. Remotion применяется для монтажа физическим лицом по
его отдельной лицензии. Музыка и чужие видеоматериалы не добавлены.


License/NOTICE/COPYING файлы Python-пакетов извлечены из файлов установленных дистрибутивов контейнера; npm license-копии получены из установленных пакетов, версии и integrity сверены с lock-файлом. Исходные файлы лицензий в пакетах не изменялись; копии проверены по SHA-256. Повторяемые данные и пути зафиксированы в JSON. Эта работа не устанавливала авторство кода, не проверяла все исключения и патентные/товарные знаки, не проводила юридическую проверку всех исходников и не заменяет анализ условий распространения модели, шаблона, эмблем и итоговой презентации.

Датированные ссылки реестра на `Fsp-private-history` обозначают закрытый архив
проверенных ранее материалов; для запуска открытого выпуска доступ к нему не нужен.
