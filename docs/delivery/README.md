Документы собираются из 19 актуальных Markdown-источников.
PDF и Word хранятся только в `gost/`, без дублирующих копий рядом.
Иллюстрации взяты из работающего синтетического стенда и имеют подписи
и запись происхождения. Видео показывает полный локальный путь;
внешний стенд имеет [ограничения](../61-temporary-domain-stand.md).
