# Локальный шрифт PDF

DejaVuSans.ttf скопирован из установленного на NAS DejaVu Sans для кириллицы
в ReportLab. Используется только для PDF; frontend использует системный sans.
Лицензия включена как DejaVu-LICENSE.txt, источник —
https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE.
Это сторонний шрифт, не собственное изображение и не подтверждённый брендбук ФСП.

JetBrainsMono-OFL.txt взята из пользовательского брендбука (вложенный
JetBrainsMono-2.304.zip); web/src/assets/JetBrainsMono-Regular.woff2 — исходный
Regular webfont из того же архива. Используется для evidence/чисел интерфейса.
