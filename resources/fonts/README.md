# Шрифты письменных документов

Tinos — свободный Times-совместимый шрифт для воспроизводимого PDF.
JetBrains Mono — свободный моноширинный шрифт команд и исходного кода.
Оба распространяются по SIL Open Font License 1.1; полные тексты лицензий
сохранены рядом. Точные источники, ревизии и SHA-256 — в `provenance.json`.

Word использует Times New Roman, 14 пт. PDF использует Tinos, 14 пт:
ГОСТ 7.32-2017 рекомендует Times New Roman, но допускает другой читаемый
чёрный шрифт размером не менее 12 пт. Проприетарные файлы Windows в Git не копируются.
